# account_style（账号结构与彩色排版契约）

本 Skill 是本公众号（农业科普与田间服务）的内容规格，叠加在 writing 基础契约与
human_writing 活人感规则之上。语言层面的禁令以 human_writing 为准；结构、
取材与排版以本文为准。

## 一、农业内容的取材与事实规则（最高优先级）

文章先检索寻山农业知识库和图库，按优先级取材：

1. 知识库中与选题直接相关的农技、产品、公司和案例原文
2. 图库中文件名、文件夹与作物或产品吻合的图片
3. 素材不足或需核验时效性时，补充农业主管部门、农技推广与科研机构的一手信息
4. 内部材料不等于独立核验；无法确认的资质、效果、产量、诊断必须保留限制

禁止编造产量、产品效果、试验案例、用药用肥处方和安全间隔期。时效数据标明日期。
正文直接解释事实与建议，不用“资料称”“资料提到”“根据资料”等套话。

## 二、结构骨架

标题 → 农事问题开场 → 01/02/03 编号大节 → 田间行动清单。

本工作流返回 ArticleDocument JSON。标题写入 titles 和 selected_title，不输出 YAML front-matter。
编号大节使用 type="heading"、level=2，content 中写节标题。每个 sections 元素必须是对象，
完整包含必需的 ending。下文 Markdown 约定只用于正文字符串与人工编辑稿，不改变 JSON 类型。

- 开场不寒暄。第一段给"根本缺陷/硬限制"式断言或一个刚发生的事实。
- 大节用 `## 01｜节标题` 格式，节标题 4~14 字。
- 结尾给可执行的观察或管理清单，说明适用的作物、生育期与需要专业确认的边界。
- 成稿正文与文末一律不出现"参考资料"来源列表：来源只用于写作取材与事实核验，
  不进入成稿（来源追溯信息由系统记录在文章元数据里，供审核后台查看）。

## 三、标志性手法

- ✗/✓ 破误区对仗，先立靶子再打。
- 一个概念一个比喻，比喻保持在同一家族内，不跨域混杂。
- 规格、对比、枚举一律表格收拢；表格单元格不用冒号。
- 关键结论句加粗，扫读粗体能读完逻辑主线。

## 四、彩色排版标记（成稿 Markdown 约定，渲染层转成样式）

- 胶囊标签独占一行，格式（标记不含冒号，避免触发 check_prose 标点禁令），格式 `%pill 标签文字 颜色`，颜色取 orange/green/purple/blue/red。
  JSON 中必须写成 `{"type":"paragraph","content":"%pill 核心思想 green"}`；
  pill 不是合法段落类型，不得写 type="pill"。
  语义固定，同类内容永远同色。
  概念 orange、核心思想 green、例子 purple、实操 blue、误区与坑 red。
- 高亮公式框 `%formula 公式内容` 独占一行。
  JSON 中同样使用 type="paragraph"，将完整标记放入 content，不得写 type="formula"。
- 正文不得再嵌其他 HTML；正文不加 H1。figure 的 asset_id 只用英文字母、数字、下划线或短横线，
  未分配时可省略，图片说明写入 caption。

## 五、去 AI 味

初稿完成后运行 `python app/skills/human_writing/check_prose.py 稿件.md`，
failures 必须清零，warnings 逐条判断。自动修订上限两轮，人工审校拥有最终决定权。
