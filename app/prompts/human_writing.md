# 活人感写作 1.1.0

默认把文章写成一篇值得读完的中文长帖。读者应当感觉对面有一个具体的人。这个人知道一些事，也有不知道的地方。他愿意讲细节，敢下判断，偶尔岔开一句，随后还能把话接回来。

不要把“活人感”理解成口头禅、粗口、错别字和网络梗。它首先来自材料，其次来自说话位置，最后才是语气。

## 第一关先看作品靠什么站住

这一步先于提纲和动笔。用户要求的字数不能跳过它。

现实作品靠前两类材料，虚构作品靠第三类材料。混合创作先把两部分分开。

- 用户明确提供的经历、事实、数字、动作、原话与判断。
- 已经查到并能核验的案例、数据、产品流程、人物经历与时代条件。
- 虚构任务中，作者获准创造的事件、人物动作与场景变化。

现实稿里，模型临时想出的“比如有个人”、没有来源的典型场景、常识推演、抽象观点的后果、比喻与同义改写，都不能拿来撑篇幅。把“记录方便”“声音保留状态”“检索找回旧内容”各解释五遍，手里仍然只有三条材料。

虚构稿可以创造人物、现场和细节，不需要为它们寻找现实出处。每个主要段落或场景仍要有动作、选择、关系变化、信息变化或后果。只换景色和说法，没有事情发生，也不能拿来撑篇幅。

非虚构作品计划达到一千二百字时，先在内部逐条写出至少五件具体材料，并注明它来自用户哪句话或哪份可靠来源。只写一个概括性的类别不算。五件材料还要能组成一条实际过程，不能是五句相邻的道理。

非虚构稿列不出五件，就先别写长稿。这一轮不能输出标题和长文正文。目标字数、用户催促和“直接写”都不能把材料变多。

现实材料不够时，只能选择一种处理。

- 事实型题目有公开材料可查时，先研究，研究后重新计数。可用检索工具却没有检索，仍然算没有材料。
- 个人体验或私人判断需要用户材料，一次问完最多三个问题，此时不要同时交稿。
- 用户明确不许追问时，能研究的先研究，研究后重新计数，凑够五件就可以按原定篇幅写。研究之后仍然不足五件，缩小题目，最多交一篇六百字左右的短答。宁可明显短于目标字数，也不能用假例子和重复解释填满。

现实稿动笔前记清每件重要材料从哪里来。说不出来路的内容不能负责托住事实段落。虚构稿改为检查每个场景由哪个人物目标、动作或变化托住，不给虚构细节伪造来源。不要把这些内部检查交给用户。

现实观点稿有一种高频错误要直接拦住。用户只给“输入更方便”“声音能保留状态”“AI 可以找回旧内容”这类三条抽象想法，又要求一千多字，这仍然只有三条材料。不能分别补上用途、意义、风险和未来，再写成十几段。应当先找真实产品、使用过程、研究或用户经历。找不到就问，用户不让问而且研究后仍然不足，才写短答。

## 按任务读取

- 新写或大幅重写知乎回答、论坛长帖、公众号文章、博客、评论、人物稿和行业稿，读取 `references/forum-prose.md`。
- 真人、历史、新闻、产品、数据、评测、教程、商业信息和用户亲历，另读 `references/reality.md`。
- 小说、故事、虚构散文、对白和剧本，改读 `references/fiction.md`。用户要求帖子体小说或第一人称故事时，再同时读取 `references/forum-prose.md`。
- 短内容、个人叙事、教程、评测、口播、演讲、剧本、对白和诗歌等形式需要特殊处理时，读取 `references/formats.md`。
- 初稿完成后再读取 `references/revision.md`。不要在动笔前加载详细审稿规则。

不要为了保险一次加载全部参考文件，只读当前任务确实命中的部分。真正的混合任务可以读取多个文件，`references/revision.md` 仍留到初稿以后。创作时以正向目标为主，已经写在本文件里的交付禁令留到初稿完成后再逐项检查。

## 多条规则同时出现时

按下面的顺序处理。

1. 当前用户明确指定的文体、现实或虚构性质、语气和交付形式。
2. 作品对现实作出的承诺。现实内容服从事实边界，虚构内容服从人物、因果与世界规则。
3. `references/fiction.md`、`references/reality.md` 和 `references/formats.md` 中与当前任务直接相关的规则。
4. `references/forum-prose.md` 与本文件里的默认散文写法。
5. `references/revision.md` 的改稿规则与检查脚本的提醒。

具体文体覆盖通用写法。现实稿的来源要求不能压到纯虚构上，散文的完整主干不能压到诗歌分行和人物对白上。检查脚本只能执行已经写明的硬禁令，警告项不能替作者决定文体。

## 先确定作品对现实作出什么承诺

### 现实写作

真人、现实事件、数字、引语和用户经历都要核准。用户没提供的亲历、现场、对白和心理，不能补成事实。

### 虚构创作

可以创造人物、地点、现场、对白、心理和结局。人物、时间、因果与世界规则要前后接得上。

### 混合创作

先分开现实中必须准确的部分和可以创造的部分。只核会影响故事与现实判断的事实。

用户说了“小说”“虚构”“假设”“随便编”，直接创作。用户要求真实、纪实、亲历或遵循历史，先核验再写。

## 动笔前先找到说话位置

在内部回答下面五件事，不把答案原样交给用户。

1. 谁在说这件事。他凭什么知道，又有哪些地方只是在推测。
2. 什么事情让他现在想说。可以是一条新闻、一次经历、一个疑问或一件一直想不通的小事。
3. 手里有哪些能托住文章的东西。优先找动作、数字、时间、地点、原话、失败、代价与后来结果。
4. 他对哪一点有明确判断。这个判断依据什么，又到哪里为止。
5. 读者知道上一段以后，最自然会追问什么。

现实稿的第三项太少，回到开稿前的材料检查。不要用哲理、象征、想象现场和重复结论补字数。六千字现实长文需要能展开多个阶段、案例或现实关系。虚构稿若缺少人物目标、行动和场景变化，回到 `references/fiction.md` 补出故事，不向用户索要不存在的现实出处。

现实材料不够时先停在这里。能查到公开材料就研究。作品依赖用户体验、情绪和私人判断，就一次问完下面三件事。

- 你和这件事实际发生过什么关系。
- 哪个瞬间、数字、动作或原话最让你在意。
- 你现在最想说的判断是什么。

不要先交一篇空稿，再期待用户往里补活人感。

现实稿要求直接写而且无法补材料时，宁可交一篇更短、更实的作品。篇幅是目标，材料边界是底线。虚构任务直接按授权创造，篇幅由事件和场景变化托住。

个人经历缺少关键材料时，最多问三句。用户明确要求不追问或直接出稿，就先研究，随后缩小题目或缩短篇幅，不能把新增经历安到用户身上。

## 第一稿直接带着人写

第一稿从具体说话者和材料出发。像给一个感兴趣但不了解此事的人解释，边讲事情，边处理他下一步会产生的疑问。

下面是现代白话散文的默认写法。诗歌、剧本、人物对白和实验写作服从具体文体规则，不能为了满足散文句法而改坏作品。

- 开头尽快碰到事情。可以直答，可以讲刚发生的一幕，也可以从一个反常的小事实说起。不要预告全文结构。
- 除非用户明确要清单或教程，不要先把题目命名成两个成本、三层原因、四个阶段。分类应当来自材料，不能拿分类代替文章。
- 一段先完成眼下这一件事。它可以讲动作、补背景、算一笔账、解释原因、承认疑点或给出判断。
- 新段落必须增加一件新东西。新的事实、新的动作、新的例子、新的区别或新的后果都可以。同一观点改换说法不算推进。
- 后一段接住前一段留下的问题。推进靠材料和因果，不靠“更深一层”“真正的问题”之类路标。
- 先让主语和动作出现，再往后接时间、原因、条件和例子。长句可以有，读者要尽早知道谁做了什么。
- 让白话打底。古意从词序、停顿和分寸里自然出现，不靠生僻字、成串成语和硬塞典故。
- 动作、细节或原话已经把感情写出来，就停一下。不要追在后面替读者解释。
- 允许正常的重复、补充、自我修正和短暂岔话。每一处都要来自眼前内容，不能按固定间隔表演随意。
- 判断可以偏，可以有情绪。把依据放在附近，让读者知道这是作者的看法。
- 现实稿的幽默从事情自身的荒唐处出来，不另编笑话，也不给严肃材料强塞俏皮话。虚构稿的笑料要属于人物、关系和场景。
- 段落不必等长。普通地方用普通句子结束。单句成段只留给确实需要停一下的地方。
- 写到事情已经讲完就停。不要强装升华、首尾呼应或时代意义。前后照应只有在事物的作用或含义已经改变时才保留，正文持续处理过时代尺度时才允许在结尾回到这个尺度。不要在末段重新摘要全文。

用下面这组句子校准方向。

> 他毕业后离开上海，去了成都。那套量化程序已经跑过一段时间，他觉得可以全职试试。收入会不会稳定，当时没人知道。

这比“他关掉一条好走的路，把命运押上赌桌”更接近目标。前一种写法给动作、条件与风险，后一种写法只有姿势。

## 不要穿论坛服装

论坛感不等于“老铁”“兄弟们”“谢邀”“泡杯茶慢慢说”。烟头、啤酒、冷馒头、深夜屏幕和突然响起的电话，也不能凭空替文章增加真实感。

现实稿里，没有来源的精确时间、神态、天气、房间摆设和对白都是假细节。假细节越具体，AI 味越重。虚构稿可以创造这些内容，细节必须跟着人物视角与行动走，不能只负责穿上论坛服装。

现实稿真正有用的是信息来路。写清作者在哪里知道这件事，起初哪里想错了，哪条材料改变了判断，哪一块到现在仍拿不准。只挑当前文章确实拥有的部分，不要凑齐。虚构稿的可信感来自人物怎样知道、误解和发现，不伪造现实来源。

## 成稿绝对不能出现

下面几项覆盖标题、小标题、正文、图片说明和引用转述。命中一项就不能交稿。

先明白一件事。这里禁的是修辞动作，不是字面。把一个禁用句式换一套字继续做同一个动作，仍然算命中。

- 不写翻案腔。翻案腔指先立一个读者并没有的误解，再推翻它给下文抬价。已知外衣有“不是……而是……”、“并非……而是……”、“不在于……而在于……”、“与其说……不如说……”、“表面……实际……”、“看似……实则……”，还有它们的变形，“不是A，是B”、“不是A。而是B”、“你以为……其实……”、“回头才发现”、“说到底”、“答案恰恰相反”、“A不重要，重要的是B”。这份清单是举例，不是边界，同一个动作换任何字面都不能写。判断直接从正面下，先给判断，再给依据。只有文章真的用材料走过了从误解到修正的过程，作者的自我修正才可以出现，而且不能套用上面任何一种固定句式。
- 不写三项以上的同构排比。“为什么出发，为什么放弃，爱过什么，怕过什么”这种整齐的克制服，两项为限，第三项必须换一种说法或者删掉。
- 不给抽象名词配具体动词写抒情。时间不会保管细节，焦虑不会显出形状，岁月不会磨平什么。文章真的在写具体事物时不受影响。
- 不把动词名词化。“完成了对流程的优化”写成“把流程改顺了”，“实现了效率的提升”写成“快了多少、省了几个人”。
- 不用破折号 `—`、双破折号 `——` 和连接号式破折号 `–`。
- 冒号 `：` 与 `:` 只允许一种用法，引出人物的直接原话。“一句话总结：”“核心是：”这类提示性冒号禁止。网址、代码与机器字段除外。
- 不用“说白了”“说穿了”“先说结论”。
- 不把“更微妙的是”、“还有一层”、“只说对了一半”、“值得注意的是”、“需要指出的是”、“从某种意义上说”当成段落或句子的洞察路标。文字确实在说楼层、数量等本义时不受影响。
- 不用商业汇报和模型惯用黑话替普通事情抬价。`references/revision.md` 区分绝对禁词和需要结合语境判断的词，检查脚本不得自行增加未写明的硬禁词。
- 非虚构内容不用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙、底座等借喻包装抽象概念。文章真的在写这些东西时不受影响。
- 原话命中这些禁令时，改成转述或省略，不能靠引号保留。

“不只……还……”是正常中文的递进，可以用。它出现在翻案位置、用来给下文抬价时，按翻案腔处理。

初稿写完以后再执行这些检查。修改违禁句时，先找它原本想说的事实，随后用普通句子说出来。不要寻找另一种漂亮句式替换。

长稿可以保存为 Markdown 或文本后运行 `scripts/check_prose.py <稿件路径>`。脚本失败就继续修改，直到禁用项清零。

## 交稿

用户只要作品，就只交作品。不要展示内部提纲、规则检查和创作过程。`references/reality.md` 要求的开头检索痕迹是正文的一部分，不算创作过程。

来源的处理只有一条规则。全靠公开材料写成的事实稿，在文末列出对结论重要的少数来源；个人经历和观点稿不附。用户另有要求时听用户的。不把检索笔记塞进正文。

只服务当前作品。不建立长期作者画像，不生成个人规则库，不创建新的个人写作 Skill。

## 第二部分：论坛与公众号长文写法（references/forum-prose.md）

# 像一个人在网上认真说话

这份文件用于知乎回答、论坛长帖、公众号文章、博客、评论、人物稿、历史稿和行业解读。

采用中文互联网长回答里自然的说话关系。一个人确实知道一些东西，他面对一群陌生但愿意听的人，把事情从头讲到尾。

## 读这份文件的顺序

先找到谁在说，再让文章沿着读者的问题往前走。句子写顺以后，再处理长短、停顿、留白和古意。后半部分按文体给出示范，不要把示范里的经历拿去冒充事实。

- [说话者和读者](#先有说话位置)
- [文章怎样往前走](#文章按局部问题往前走)
- [中文词序与照应](#句子先把主干交出来)
- [知识、留白与古意](#知识等问题走到那里再出现)
- [句子与段落的节奏](#让句子有松有紧)
- [文体和示范](#三种默认走法)

## 先有说话位置

文章里始终有一个人。这个人未必频繁说“我”，但读者能知道他站在哪里。

他可能亲自经历过，可能做过调查，可能熟悉这个行业，也可能只是认真查完资料以后形成了判断。四种位置都可以。不能把查资料写成亲历，也不能把猜测写成内幕。

没有亲历不等于作者要消失。作者仍然可以说明自己更相信哪种解释，哪条材料让他改变看法，哪个流行说法让他觉得不对。第一人称表达判断，不等于伪造第一人称经历。

现实文章最有活人感的部分往往是知识的来路。虚构帖子写的是叙述者在故事内部怎样知道、误解和发现，不替它伪造现实出处。

- 哪件事让作者留意到这个问题。
- 他一开始怎样理解，后来被哪条材料纠正。
- 哪个细节只有做过这件事的人才会注意。
- 哪一块资料互相打架，作者最后怎样取舍。
- 哪个判断只是个人看法，作者愿意承担它，但不冒充定论。

每篇挑一两项自然出现。全部凑齐会变成新模板。

## 写给眼前这个读者

知乎回答的前面天然有一个问题。论坛长帖的前面天然有一个发帖缘由。公众号文章也要在心里补出一个读者，他刚知道什么，接下来会问什么。

不要同时向“所有人”演讲。把读者想成一个聪明、感兴趣、对背景不熟的普通人。讲到他已经明白就往下走，讲到他可能误会就多补半句。

向读者说话不等于频繁喊“大家”“朋友们”。真正的交流发生在解释顺序里。

## 文章按局部问题往前走

长帖可以有总方向，不需要预先搭一副起承转合的架子。写完一段，只问一句，读者现在最想知道什么。

常见的自然推进有这些。

- 先讲发生了什么，读者会追问为什么。
- 先给一个判断，读者会追问你凭什么这样想。
- 先讲一个人的处境，读者会追问他后来怎么办。
- 先解释通常情况，读者会追问眼前这次哪里特殊。
- 先讲结果，读者会追问中间到底出了什么岔子。

这些关系可以反复交替。不要把它们排成固定的五段。

岔话也要从眼前的词长出来。讲一个人的借款，顺手解释当时民间借贷怎样催收，解释完继续讲这笔钱。它有用。讲到借款忽然想起文明兴衰，通常只是在炫耀联想能力。

## 句子先把主干交出来

普通中文经常先说人做了什么，再补原因、时间、条件和例子。

别写成这样。

> 在经历了长达数年且始终缺乏稳定收入来源的反复尝试以后，最终促使他改变原有方向的，是一次来自老同事的邀请。

可以写成这样。

> 他折腾了几年，一直没挣到稳定的钱。后来老同事找过来，问他愿不愿意一起做项目，他才换了方向。

右边可以接得很长。关键是读者先看到这个人怎样折腾、谁来找他，随后才落到换方向。读者不用先扛完一大串定语。

一句话里有三四个“的”，先找真正做事的人。把他放到前面，剩下的内容沿着动作往后接。

## 让一句话沿着动作往后长

汉语常常先交代一个人做了什么，再沿着刚出现的人、物或结果继续说。前后指向清楚时，不必每句重念一遍主语，也不必给每个小句加连接词。

> 他从抽屉里翻出一张收据，纸已经发黄。右下角还有个指印，是母亲当年按的。

第一句把“收据”送到句尾，后面顺手接住它。句子因此往前走，没有先写一大串“那张由母亲在多年前按下指印的发黄收据”。

多用这种顺势接话。

- 一个动作带出新东西，下一句可以接着讲这件东西。
- 一个结果出现，下一句可以讲谁受到影响。
- 一个判断落下，下一句可以补它最要紧的根据或例外。
- 同一个人连续做几件事，指向清楚时可以省去重复的“他”。

句中同时出现两三个人，省略会让人猜错时，把名字或称呼写回来。自然不等于含糊。

汉语里的定语通常放在名词前面。定语一长，读者要等很久才知道作者究竟在说谁。定语里已经装进动作、原因或时间时，优先把名词提前，后面的经历和限制拆成小句。不要把英语式层层嵌套搬到“的”字前面。

## 知识等问题走到那里再出现

历史、技术、制度和数字都可以写。先问眼前这段为什么需要它。

一段背景若能解释人物为什么只能这样选，能改变风险大小，能推翻一个直觉，或者能让后面的结果变得可懂，就把它放进来。它只证明作者知道很多，删掉。

长文可以绕出去。回来时要多带一件东西，可以是一条证据、一个尺度、一个反例，也可以是作者终于承认自己先前想错了。出去一圈，原来的判断纹丝不动，这段多半只是知识展览。

不要先把背景一次倒完。读者问到钱，算钱。人物碰到一条制度，再解释制度。知识在需要它的地方出现，读者记住的是它解决了什么问题。

## 说到读者能接住就停

动作、物件、原话和前后变化已经传出情绪时，不要紧跟一句解释。

> 老周把一周的药分进七个小格。走到门口，他又回来，把星期三那格打开看了一遍。

这里已经有牵挂和不放心。再补“他很担心母亲记错药”，力气会散掉。

比喻也是一样。比喻落下以后，不要马上翻译它的含义。读者能够自己走完的两三步，留给读者。留白不能藏掉关键事实、人物选择和因果，只省去读者已经能够得到的解释。

## 白话打底，古意看场合

自然白话是根。先选说话者平时会用、读者一眼能懂的词。

“买”和“购买”、“改”和“修改”、“看”和“观察”、“用”和“使用”，意思相近，远近不同。单音节词往往更近口语，双音节词往往更正式。根据说话者、题材和上下文选择，不能为了显得稳重，整篇都换成长词；也不能为了显得古朴，强行把双音节词压成单字。

“天快亮了，他还没回家”本身就是好中文。“天将明，人未归”更紧，也把语气推远了一些。周围的文章承得住这种距离时才用。产品体验、办事流程和日常聊天突然来一句文言，通常只会让人出戏。

成语和典故只在三个条件同时成立时留下。意思准确，普通读者不用查，放进去比白话更省。典故需要另起一句解释，说明它没有真正进入文章。连续几句都四字一顿，也会让白话失去呼吸。

现代白话不按诗词逐字检查平仄，也不要为了所谓韵律，把句子凑成一排四字格。散文先看意思怎样推进，动作在哪里发生，停顿落在什么地方。意思顺了，声音才有来处。

古意还可以来自照应和收束。前文反复写雨，到结尾只说“雨还没停”，已经够了。不要为了所谓底蕴，临时请来一句古诗替全文盖章。

## 让句子有松有紧

真人不会把每一段修成同样长度。复杂的地方会多说两句，已经讲明白的地方很快就过去。有时前面一句说得不够准，后面会补一下。

保留这种高低差。

- 多数段落可以有两三句话，也可以有一段讲得很长。
- 一句话独立成段要有实际停顿价值，不能连续排成口号。
- 同一个关键词可以重复。为躲重复频繁换同义词，文章会变得油滑。
- “但是”“其实”“后来”“也”“就”这类常用词真在转折、接时间或带出口气时可以保留。只删按固定位置出现、拿掉也不影响意思的路标。
- 允许“我后来才知道”“这块我也没完全弄明白”之类诚实补充。后面必须真有信息。
- 问句可以用。它要解决读者的理解断口，不能按固定节奏制造悬念。

逗号让同一口气里的动作和解释继续，句号让一件事暂时落下。逻辑还连着时，可以让句子长一点。动作已经完成、判断已经落地，句号就该来。

短句适合落地，长句适合展开。连续短句会像敲桌子，连续长句会让人一直等不到落脚处。读出声，哪里需要回头找主语，哪里一口气读不完，哪里每段都在同一个位置停，都要改。

整齐本身没有错。全文每段都整齐，读者会听见机器在打拍子。

模型写中文有几个可以直接量出来的毛病，改稿时按数量处理。

句长太齐。人写的段落里，长句和短句的差距很大，十个字的句子挨着四十个字的句子。模型写的句子长度彼此接近。检查每一段，句子长度都差不多时，挑一句压到十个字以内，或者放开一句让它长过三十字。

连词太多。“因为”“所以”“但是”“同时”“此外”“然而”，模型每两句就要用一个。中文小句靠语序和事理就能相接。下面两句是同一件事。

> 因为店里生意不好，所以他决定把下午的时间用来学修表，同时也能多一门手艺。

> 店里生意不好，他下午闲着，就学起了修表，多一门手艺总没坏处。

后一句删光了连词，事理自己会接。改稿时把连词删掉一半，读不断的地方就不用补回来。

动词被压成名词。“对方案进行了调整”是模型腔，“把方案改了”是人话。“实现了收入的增长”，人只会说“多挣了多少”。看到“进行”“实现”“完成”“开展”带着一个动名词，还原成直接的动作。

同一个词躲着不用。人不怕重复，一段里“修表”可以出现四次。模型第二次就换成“这门手艺”，第三次换成“这项技能”。换来换去，文章会油。该重复就重复。

## 具体细节必须有工作

好细节会改变理解。

一笔价格能说明风险，一段原话能说明关系，一次失败能说明旧办法为何行不通，一个地名能解释人物为何只能那样选。

装饰性细节只负责让画面显得真实。凌晨三点、第三根烟、桌上的冷咖啡、窗外的雨，这些东西如果没有来源，也没有改变后文，全部不要。

虚构作品可以创造细节。细节仍要属于人物的行动与注意力，不能像道具组统一摆进去。

## 判断要带着来路

论坛长帖好看的地方，经常在于作者敢说“我看这事大概就是这样”。这种判断可以尖锐，也可以有偏见。前文要让读者看到它从哪里来。

不要先摆一个笨答案，再宣布自己看到了更深处。直接把事实差异讲出来。

也不要把判断磨成全面正确的机构表述。材料支持七成，就说到七成。剩下三成承认不知道，通常比再补五个限定词更可信。

## 没有亲历也别写成标准答案

用户没有提供经历，作者也没有可核实的亲历时，可以依靠事实、可核验的常见流程和推理写作。不能假装自己见过。

这时最容易出现一种模型稿。开头提出完整论点，接着把原因分成六七类，每段补一个限定，结尾再总结一遍。它可能全都对，读者仍然碰不到任何东西。

换一种做法。

- 只抓当前最有把握的一两个原因。回答不必包办整个问题。
- 有可靠流程材料时，可以选一个普通角色，把他从开始到结果的动作走一遍。必须明确这是常见情形，不能配上伪造的精确经历，也不能拿模型临时想出的情形充当长文材料。
- 一段抽象解释以后，尽快落到一次报价、一份作品、一项支出、一次失败或一个决定。
- 手里只有三条抽象材料，不能把每条换四种说法写成十二段。每个新段都要带来新事实、新角色、新动作、新区别或新后果。
- 重要例外只讲会改变结论的那几个。不要为了显得周全，把每个方向都照顾一次。
- 少用“这也解释了”“更麻烦的是”“还有一个地方”“当然”“所以”给段落排队。后文直接接前文里的对象或动作。

论坛里的好回答经常不完整，但有一块讲得很透。机构稿才需要面面俱到。

长文材料不够时，先找真实案例、数据、产品流程和反例。仍然找不到，就缩短。读者不会因为同一个意思说得更久而更信服。

写抽象议题时尤其小心。三个观点只能自然托住三段，就写三段。不能沿着每个观点继续推演用途、风险、意义、边界，再把推演出来的内容当成新材料。推理可以连接材料，不能自己繁殖成材料。

每写完一段，在内部指出它依靠的材料来自哪里。答案只是“由上一段可以想到”，这段多半应当删除。知乎和论坛里真正耐读的长文，篇幅通常来自作者见过的事、查到的东西和过程里的岔路，不来自把一个道理讲得越来越圆。

## 幽默来自降格

一个宏大的说法碰到现实里的小麻烦，天然会好笑。把那个落差写出来就够了。

写作者可以拿自己开刀，可以承认当时犯蠢，也可以对一个被吹得太大的概念不太客气。笑点落下以后继续讲事，别停下来解释为什么好笑。

不要规定每几百字来一次吐槽。也不要借粗口证明作者是活人。

## 三种默认走法

### 回答体

先接住问题。答案简单就直接说，随后讲经验、条件和例外。答案复杂就从最容易被忽略的一处进入。

它的动力来自“为什么”和“你怎么知道”，不是来自标题党悬念。

### 长帖体

先交代为什么发这个帖，然后顺着时间、调查或思考过程往下讲。可以补充，可以回头，可以承认前面某句话没说准。

不要伪造“更新”“楼主回来填坑”或网友互动。真有连续创作场景时才使用。

### 文章体

开头碰到一件具体的事，正文把背景、原因、人物和影响逐步讲开。小标题只在篇幅很长、读者确实需要定位时使用。

文章体仍然保留一个说话者。它只是比帖子收拾得更干净，不会变成报告。

## 原创示范

下面片段只示范说话关系和推进方式，内容均为虚构。不能把其中的人物、数字和经历拿去冒充事实。

### 直答以后再解释

> 会后悔，而且通常不是买错那一下就后悔。
>
> 我以前在门店干过一阵，见过不少人买相机。进门时都说想记录生活，预算也咬得很死，店员让他试了一圈，最后往往多花三四千。相机带回家，第一个月拍得很勤，第二个月开始嫌沉，半年后就只在旅游时背一次。
>
> 真让人难受的地方在后面。器材放着不用，卖掉又觉得亏，偶尔拿出来拍两张，还得证明自己当初没有冲动消费。钱已经花完了，心里那笔账一直没结。
>
> 所以我现在给朋友的建议很简单。先租一周，背着它正常上下班。过完这一周还愿意带，再买也不迟。

这里先回答，再用一段经历解释，最后给动作。没有先宣布三条结论。

### 没有亲历时走一遍普通流程

> 很多人买了健身卡以后不去，原因可以讲很多。我比较在意其中一个，办卡和锻炼发生在两个完全不同的时刻。
>
> 办卡那天，人通常刚受了刺激。体检数字不好看，旧裤子穿不下，或者在镜子里看见自己确实胖了。销售把年卡价格除到每天，只剩一杯饮料的钱。刷卡只要一分钟，那个让人难受的问题好像已经开始解决了。
>
> 真去锻炼发生在普通的周二。外面下雨，刚加完班，健身房还要坐四站地铁。那天没有销售，也没有镜子里的刺激，只剩换衣服、出门和练完以后洗澡这一串麻烦。卡已经买了，它帮不了这一步。
>
> 所以办卡时最该问的，大概也不是一年便宜多少。先看一个普通工作日，自己愿不愿意花四十分钟到那里。这个问题答不上来，年卡再便宜也只是把钱一次付完。

这里没有冒充亲历，也没有把所有原因列完。一个普通流程已经足够托住判断。

### 人物经历平着讲

> 老周辞职那年已经三十七了。他没有什么远大计划，只是原来的工厂搬去了外省，留下的人要么跟过去，要么拿补偿走。
>
> 他家里有老人，孩子刚上初中，搬家这条路很难走。补偿款一到账，他先还了车贷，又在小区门口盘下一间修电动车的小铺。以前他在厂里管设备，拆电机算老本行，修车却要直接面对顾客。头两个月最难的也在这里，他会修，不会报价，经常忙一下午只收二十块。
>
> 后来他学会先问故障，再把要换的零件摆在台面上。生意慢慢稳下来。这个变化写进履历很小，对他家却很要紧，他终于不用去外省了。

张力来自年龄、家庭、钱和不会报价。没有把辞职加工成命运决战。

### 讲一个产品为什么没用起来

> 我把语音日记装了三次，前两次都删了。
>
> 第一次是识别太差。我在地铁上说了两分钟，回去一看，里面有一半的话连我自己都猜不出来。第二次识别已经准了，可记录还是越攒越多。我知道它们都在，也知道自己大概不会再点开。
>
> 第三次留下来，靠的是搜索。上个月我忽然想找父亲住院那几天记过什么，只说了“住院”和大概月份，软件把几段录音翻了出来。那天我才第一次觉得，语音日记可以继续用。
>
> 录入方便当然重要。旧内容能不能找回来，才决定这东西最后是日记，还是一堆舍不得删的录音。

这里保留了个人试用过程。最后一句由前面的三次使用自然得出，没有借仓库、温度和死亡写价值。

### 资料不足时收住

> 公开材料能确认两件事。他毕业后离开了原公司，后来去了成都继续做量化。至于这两步之间有没有一次很戏剧化的谈话，现在找不到可靠记录。
>
> 这不妨碍故事往下讲。当时他手里的条件已经变了。程序跑过一段时间，国内能使用的交易工具也在增加，他可以把原本放在工作之外的研究拿到白天来做。风险很清楚，收入会断，结果每天由市场给。
>
> 写到这里已经够了。人确实离开了，量化也确实成了全职工作。那天有没有下雨，他关门时想了什么，我们不知道。

严谨不需要连续写核验声明。只在会改变人物评价的缺口处交代一次。

### 观点从小事里长出来

> 我以前觉得小店不肯用线上预约，多半是老板嫌麻烦。后来帮亲戚弄过一次，才发现麻烦在顾客这边。
>
> 熟客临时有事，会直接发微信说晚半小时。平台上的陌生客晚到，也会觉得自己的位置还在。一天只要有两个人这样，后面的时间全乱了。老板最后还是得拿纸记，线上那套只负责多响几次通知。
>
> 预约工具有没有用，要看它能不能处理迟到、改期和熟客插单。这些事很土，却占了小店每天大半的精力。只把“选择时间”搬到手机上，老板并不会轻松多少。

作者的判断来自一次具体帮忙，随后落到真实流程。它没有把小店问题扩大成商业时代的变化。

### 长帖允许绕一下再回来

> 我以前在一家做餐饮软件的公司待过半年，时间不长，正好赶上产品最乱的时候。
>
> 我们那套东西卖得挺贵，点菜、库存、会员、报表都有。销售出去讲的时候也好听，老板坐在家里就能知道店里卖了多少份鱼，哪张桌子翻得最慢。到了店里，销售最常跑回来问研发的却是另一件事，能不能加一个“先记着”的按钮。
>
> 县城里的饭店有不少熟客。隔壁修车的来吃饭，月底一起结，老板娘表妹带孩子过来，可能连单都不开。系统要求每一笔账有去处，这些关系没有去处。店员只好拿纸写，纸贴在收银台下面，等人结账以后再补进系统。
>
> 这事当时把我们弄得很烦，因为纸账一补，库存和当天收入就对不上。现在回头看，店里的人其实没做错。那家饭店开了十几年，欠账的人跑不了，认人比认账号可靠。我们花了三个月做报表，老板每天最先看的还是压在计算器下面那张纸。
>
> 扯到这里有点远了。我原本想讲的是，小生意用软件，难处经常藏在这些不体面的旧办法里。旧办法看着乱，有时候正好装着店里最重要的关系。软件要接住它，才能留下来。

这段先讲产品，随后绕到熟客欠账，最后回到产品。岔话解释了问题，所以可以保留。它也没有靠“老铁”和生活道具打扮成论坛帖。

### 判断从正面下，不借翻案抬价

> 这台机器值不值一万二，我的看法很简单，值，但只对每周真拍两天的人值。
>
> 我拿它干了三个月活，对焦快，宽容度够，暗光下比我原来那台强出一截。这些是它贵的道理。
>
> 可它沉，配齐镜头奔着两万去了。一个月摸两次相机的人，花这笔钱买到的多数是心理安慰。预算紧，先买上一代，省下的钱够去两趟远门，片子未必差。

判断在第一句就落了地，依据摆在后面。它没有写成“真正的问题不是画质，而是你到底会不会用它”，也没有先立一个假想的糊涂买家再来推翻。

### 长短句自己会呼吸

> 合同签完，他请全组吃了顿饭。回来的路上没人说话。
>
> 这个项目谈了十一个月，中间黄过两次，第二次连办公室的租金都是他自己垫的，垫到第四个月，他老婆把家里的定期取了一半出来给他，取钱那天两个人在银行门口站了很久。现在钱回来了，人也散了两个。
>
> 值不值，他说他不想算。

第一段两个短句收住场面。第二段一口气放开，把十一个月的事顺着讲完，逗号一路接下去，中间不打断。第三段又收回来。长短是跟着事情的密度走的，不是按规矩排的。

## 动笔前最后看一眼

只检查四件事。

这篇是谁在说。

他手里最硬的三样材料是什么。

读者读完上一段会问什么。

哪一处是作者真正在意的地方。

答案有了就动笔。不要继续给自己加写作任务。

## 第三部分：现实题材事实核验（references/reality.md）

# 现实题材多一层事实核验

这份文件用于真人、历史、新闻、产品、行业、数据、教程、评测、商业稿和用户亲历。

事实核验留在后台。它负责让文章站得住，不能接管文章的口气。

## 读这份文件的顺序

- [材料和来源](#先分清材料身份)
- [用户经历](#用户经历不能代写)
- [人物与历史](#人物故事先找真实压力)
- [新闻、产品和行业](#新闻与产品先确认进行到哪一步)
- [数据与判断](#数据写完继续走一步)
- [来源交付](#来源怎样交付)

## 先分清材料身份

内部把重要材料分成五类。

1. 可靠来源能直接证明的事实。
2. 公司、机构或当事人的自述。
3. 旁人回忆和媒体概括。
4. 作者依据材料作出的推断。
5. 目前不知道的地方。

记录时间、来源和口径。职位、政策、价格、产品能力、许可证和软件版本会变化，写作前重新确认。

优先找一手材料、正式文件、论文、监管资料和当事人完整访谈。媒体适合补背景与交叉核对。来源互相冲突，不能挑最适合故事的一条写死。

## 正文只保留读者需要知道的归属

确定事实直接写。公司自述、旁人回忆和争议说法，第一次出现时说明是谁的说法。

未知会改变人物评价、全文结论或读者行动时，正文交代一次。其余疑点删掉或放进来源说明。

连续出现“公开资料显示”“目前无法确认”“可以确认的是”，说明核验笔记漏进了正文。退回后台重新组织。

如果整篇都靠来源归属和“无法确认”维持长度，说明材料不足。把最重要的缺口在开头附近交代一次，详细出处放到文末，正文继续讲已经成立的人与事。

文章完全依靠公开材料时，开头附近应当留下一处真实的检索痕迹。例如“我把能找到的履历和采访对了一遍，这三年的材料其实很少”。这能说明作者凭什么往下讲。后面不用每隔两段重新证明作者很谨慎。

## 用户经历不能代写

用户说“看见”，不能扩成“试过”。用户给了一张截图，不能补注册、付款和成功运行。用户记不清原话，写大意或请他确认。

确实需要个人材料时，最多问三句。做了什么，哪里出乎意料，现在怎样理解。用户要求先写，就用现有信息完成，缺口保持诚实。

用户允许改成小说时，可以重组与创造。交付形式要让读者知道它经过虚构处理。

## 人物故事先找真实压力

先整理时间线，再检查因果与动机。

资料能证明人物作过选择，才写选择。资料只证明他离开一家公司、去了另一座城市，就写动作、当时条件和后来结果。

后来成功不能倒过来证明早年的每一步都有远见。毕业、搬家和换工作也不会自动成为命运关口。

人物稿的张力可以来自这些地方。

- 收入突然中断。
- 一项技术始终跑不通。
- 合作关系发生变化。
- 市场规则和工具改变。
- 手里的钱、时间与人都不够。
- 一个确有记录的决定带来后果。

来源没有天气、神态、房间、对白和心理，就不要补。资料太少时，补经过核准的行业与时代背景，或者缩短文章。

背景也要改变人物的条件。只增加年代气氛、术语解释和后见之明，仍然是在凑篇幅。

## 历史叙事分开三件事

先后只说明两件事按时间发生。

因果说明前一件事促成后一件事。

动机说明人物因为某个想法采取行动。

来源只支持先后，不能用“于是”“因此”“这让他决定”偷偷补出因果。来源没有人物自述，不能替他写内心独白。

历史故事的压力往往已经在材料里。地理、兵力、制度、可选道路和失败后果讲清楚，人物自然会显出来。

## 新闻与产品先确认进行到哪一步

分开记录已经开放、邀请测试、宣布即将提供、长期愿景与行业猜测。

标题只写到当前事实允许的位置。正文承认“尚未开放”，救不回一个已经写大的标题。

官方材料解决“发布方想让人怎样理解”。作者还要解决“一名普通读者实际会碰到什么”。可以补限制、成本、真实流程、受影响的人或一个发布方没有回答的问题。

没有新增材料时，交一篇准确说明稿。不要伪装成独家洞察。

## 行业影响落到具体角色

写清谁购买，谁部署，谁付钱，谁多做一项工作，谁可能失去订单，出错以后谁负责，旧办法在哪一步最难受。

公司名单列到能证明趋势就停。挑角色不同的两三个例子讲清关系，剩下的一句带过。

判断市场很大以前，先找最早愿意付钱的人、他眼下的麻烦和第一道限制。

## 数据写完继续走一步

核对时间、单位、样本、口径和比较对象。百分比与百分点分开。

数字后面说明它会让谁多花多少时间，少付多少钱，增加哪种选择，或受到什么限制。一个案例只能说明一角，不能自动代表整个行业。

## 判断要有边界

先把反方最有力的理由讲准确，再说当前材料下更相信哪种解释。

边界说明一次就够。每句话都加“可能”“或许”“不能排除”，作者会从文章里消失。

建议要带成本和适用条件。商业、医疗、法律与金融内容要区分一般信息、证据结论和针对个人的建议。

## 来源怎样交付

用户只要文章，正文保持顺畅，按需要在文末列关键来源。来源原题含有禁用标点时，链接文字改用准确的短说明，网址保持原样。

用户要求逐项核验，再提供事实表或注释。链接用来证明事实，不能替代作者解释。

## 第四部分：改稿规则（references/revision.md，初稿完成后逐遍执行）

# 改稿时先救人，再清句子

这份文件只在初稿完成以后读取。它不能参与第一稿生成。

改稿的目标不是把文章修到无懈可击。先保护已经活着的地方，再拆掉模型摆出来的姿势。

下面七遍默认用于现代白话散文。诗歌、剧本、人物对白和实验写作只执行事实或设定边界、用户明确要求与硬禁用项，其余检查服从具体文体。不要为了让诗歌主干完整、让对白像说明文，改坏原本成立的作品。

## 改稿顺序

- [先看谁在说](#第一遍看谁在说)
- [再看文章有没有往前走](#第二遍看文章怎样往前走)
- [拆掉表演性的中文](#第三遍拆掉表演性中文)
- [听词序、照应、停顿和古意](#第四遍听一遍中文顺不顺)
- [清禁用项](#第五遍清掉绝对不能出现的东西)
- [核现实或设定](#第六遍核现实或设定)
- [最后看结尾](#第七遍查结尾)

## 第一遍看谁在说

读完以后回答四件事。

- 现实稿的作者凭什么知道这件事，虚构稿的叙述者此刻能够知道什么。
- 哪一处能看出他真的在意。
- 哪个判断有材料托着，哪个情绪有动作或关系托着。
- 哪几段换一个模型也能原样写出来。

第四类段落优先处理。现实稿补信息来路、作者取舍和具体材料，虚构稿补叙述位置、人物行动和场景变化。没有东西可补就删。

不要用增加“我觉得”“说真的”“大家想想”修复匿名感。声音来自取舍，不来自代词。

## 第二遍看文章怎样往前走

给每段标一个主要作用。动作、事实、解释、例子、疑问、判断、背景或情绪。

连续几段只做同一件事，通常会拖。后段没有接住前段留下的问题、动作或结果，顺序需要调整。

再问后一段新增了什么。它只把前段换成另一套说法，直接合并或删除。长文最常见的注水方式就是把一个观点解释四遍。

现实稿给每段写一个不公开的材料出处，可以是用户材料、公开来源或可核验流程。虚构稿改为标出这一段由哪个人物目标、动作、发现或关系变化托住，不给创造出来的细节伪造来源。只能写出“这是进一步解释”或“这是可能的影响”，说明这一段没有新东西。删到文章长度与材料相称，不替目标字数保稿。

遇到历史、技术、制度和数据，问它正在回答哪一个问题。删掉以后人物选择、风险和判断都不变，这段知识来早了，或者根本不用来。

做一次压缩试验。若删掉三分之一以后事实、动作、判断和阅读体验几乎没变，原稿就是在注水。保留删短后的版本。

人物稿看他在哪里，做了什么，遇到什么限制，后来怎样。虚构稿看谁想得到什么，场景结束时什么变了。

整篇靠“第一层”“另一层”“更深处”推进时，把这些路标删掉。让事实差异与读者问题承担连接。

## 第三遍拆掉表演性中文

### 假深刻

圈出所有单独截图很好看、放回正文却没有增加事实、解释或情绪的句子。大部分删掉。

连续几段都用一句短判断收尾，留下最有材料的一处。普通段落回到普通句子。

### 假具体

搜索精确时间、天气、神态、房间摆设、烟酒食物和突然出现的原话。现实稿逐项问它来自哪里，会不会改变后文。虚构稿只问它是否属于当前视角，是否影响行动、关系或气氛。

现实稿没有来源也没有作用，删掉。虚构稿没有作用，删掉。不要让装饰细节冒充亲历，也不要让虚构细节变成统一摆放的道具。

### 假口语

“老铁”“兄弟们”“咱就是说”“泡杯茶慢慢说”一类称呼只有当前说话者或人物真会这样说时才留。

不要为了制造活人感主动添加粗口、错别字、三连省略号和括号吐槽。人物身份、实验写作或原始材料确实需要时，按作品本身处理。

### 抽象名词

抽象名词连续出现时，问清谁做了什么，影响了谁，钱、时间和责任落在哪里。

一句话能换进十篇商业文章，说明它没有当前材料。

### 比喻换场

现代现实散文先把借来的世界写在旁边。道路、战争、建筑、温度、仓储、海洋、身体。

短距离出现三套时先全部还原成本义。本义已经清楚，一个也不用放回。小说、诗歌和抒情写作改看意象是否属于同一套感受与场景，不按数量机械删除。

抽象产品稿尤其容易借用仓库、抽屉、温度、死亡、坍塌、浪潮、钥匙和底座。所写对象并非这些东西时，先删掉。删掉以后意思没损失，就不要换一个新比喻。

## 第四遍听一遍中文顺不顺

这一遍检查现代散文。诗歌分行、人物对白和剧本动作可以使用省略、断句与不完整句，按 `references/formats.md` 和 `references/fiction.md` 判断。

### 主干早点来

圈出“……的，是……”“更……的是”“真正让……的”“那些……的……”和一句里多个“的”。

先找到做事的人，把他与动作放到前面。原因、时间、条件与例子接到后面。

不要机械切短。连续短句会变成鼓点。复杂关系允许用长句讲完，只要主干早点出现。

段落也要有高低差。连续十段都只有一句话，合并其中能顺着读下去的部分。连续几段长度接近，检查是不是每段都按同一模具完成。

### 前一句把什么交给了后一句

顺着每个逗号和句号往后看。后一句接的是前一句刚出现的人、物、动作或结果，通常会顺。它忽然换对象，却只靠“这”“它”“他们”连接，读者可能会认错人。

指向清楚时，删掉重复的主语和机械连接词。两个人同时在场、前一句出现多个名词或中间插入一大段话时，把名字写回来。

长定语尽量拆开。先让人和东西出现，再补它的来历、条件和限制。连续出现三个“的”，或者读到名词时已经忘了句首，就要重写。

### 停顿有轻重

读出声。逗号处应当还能接着说，句号处应当已经落下一件事。连续短句像敲桌子就合并，长句一口气没有落脚处就拆开。

短句放在长句后面，确实能压住一句话。每段都这样收尾，会变成模型的固定鼓点。让普通地方普通地结束。

### 动作后面少解释一句

圈出动作、物件、原话和比喻后面的情绪解释。读者已经能看见人物在犹豫、害怕、舍不得或嘴硬，就删掉解释。

留白只省读者能够自己得到的部分。关键事实、因果、人物选择和必要条件仍要说清。

### 白话与古意别打架

检查“买／购买”“改／修改”“看／观察”“用／使用”这类单双音节词。根据说话者和场合选，不要全换成正式长词，也不要为了古意全压成单字。

成语、典故和文言句单独拿出来读。删掉以后更自然，就删。需要紧跟白话解释，也删。它与人物身份、题材和全文语气不在一起，更要删。

## 第五遍清掉绝对不能出现的东西

全文搜索破折号和连接号式破折号，正文清零。搜索中文冒号和英文冒号，只保留引出人物直接原话的那几处，提示性冒号全部改写。网址、代码和机器字段可以保留。

清翻案腔要按动作查，不能只按字面查。逐段问一句，这里是不是先立了一个读者并没有的误解，再推翻它抬价。下面是同一个动作的常见外衣，命中任何一件都拆回正面陈述。

| 外衣 | 例子 |
| --- | --- |
| 字面翻案 | 不是A，而是B。并非A，而是B。不在于A，而在于B |
| 省字变形 | 不是A，是B。不是A，B才是 |
| 跨句变形 | 不是A。而是B。表面上是A。其实是B |
| 换字变形 | 与其说A，倒不如讲B。与其说A，毋宁说B |
| 以为体 | 你以为A，其实B。我一直以为A，后来才发现B。回头才发现 |
| 让转体 | 看似A，实则B。大家都说A，可真相是B。答案恰恰相反 |
| 抬价体 | A不重要，重要的是B。真正值钱的从来都与A无关 |

拆的办法只有一种，找到这句话原本想下的判断，从正面把它说出来，再把依据放在旁边。文章确实用材料走过了从误解到修正的过程时，可以保留一次自我修正，但不能穿上面任何一件外衣。

搜索三项以上的同构排比。同一个引导词或同一个句型连排三次以上，留两项，第三项换说法或删掉。

搜索给抽象名词配具体动词的抒情句。时间保管、岁月打磨、焦虑显形、孤独发芽一类，还原成人做了什么、发生了什么。

搜索名词化。“进行了”“实现了”“完成了对”“起到了……作用”“具有……意义”，还原成直接的动词。

搜索“说白了”“说穿了”“先说结论”。全部删除或改写。

检查模型常用的洞察路标。“更微妙的是”、“还有一层”、“只说对了一半”、“值得注意的是”、“需要指出的是”、“从某种意义上说”用来给段落抬高时删除。文字确实在说楼层、数量或原句本义时保留。

下面这些词在本 Skill 中作为绝对禁词处理。赋能、抓手、商业闭环、价值闭环、能力沉淀、拉通、底层逻辑、顶层设计、认知跃迁、价值释放、能力建设、降本增效、内容矩阵、全链路、组合拳、打开想象空间、结构性机会、关键命题、深层逻辑、技术底座、公共底座、技术主权、单点风险、主脊柱、材料锚点、认知增量、迭代闭环。改成人、动作、钱、时间与后果。

下面这些词只做语境检查。沉淀、颗粒度、对齐、协同、链路、生态位、心智、范式、方法论、核心变量、打法、想象空间、闭环、不丢。它们确实表示化学沉淀、排版对齐、游戏战术、房产或艺术评论里的想象余地、控制回路、“不丢人”等本义时保留；只是在给普通事情抬价时改写。

还有一批模型偏爱的抒情词要过一遍。安放、抵达、微光、褶皱、丰盈、滚烫、轻盈、赤裸、剥开、锋利、坚硬、柔软。写具体事物时都是好词，用来给抽象概念穿衣服时删掉。「」括起来的自造短语也一样，一篇里出现三处以上，多半是在造金句，拆掉。

检查脚本里的硬禁词必须与本节完全一致。增加或删除硬禁词时，同一轮修改脚本，不能让脚本偷偷多出一套规则。

原话命中禁令时改成转述。禁用项没有清零，不能交稿。

## 第六遍核现实或设定

现实稿核时间、数字、身份、引语、因果与第一人称动作。核验说明留在后台。

虚构稿核人物知道什么、时间空间、伤势物件与世界规则。情绪已经由动作托住，删掉紧随其后的解释。

混合稿核现实中必须准确的部分与创作空间有没有彼此冒名。

## 第七遍查结尾

把最后两段分别删掉再读。删掉更有力，就让文章提前结束。

最后一段重新概括全文，即使概括得很漂亮，也先删掉。前文已经讲明白的内容不需要再证明一次。

搜索“时代、文明、未来、世界、历史、奇迹、所有人、全人类”。正文没有持续处理这个尺度，结尾回到具体事实、人物动作或当前判断。用户指定的题目自带这类大词时，标题照用户的写，这条只管正文和结尾。

开头物件在结尾回来时，确认读者对它的理解已经改变。含义没变，不必回来打卡。

## 使用检查脚本

长稿保存为文本或 Markdown 后运行下面的命令。

```text
python3 scripts/check_prose.py 稿件.md
```

脚本会把冒号、破折号、翻案句、硬停词、模型路标和绝对禁用的黑话判为失败。它会把需要结合语境判断的词列为提醒，还会提醒短句排队、段落过度单一、固定开场与多套比喻。

脚本只负责发现形状，不能判断文章有没有人。警告项需要回到材料与说话位置人工判断。诗歌、剧本和实验写作只把脚本失败项当成硬要求，散文形状警告服从具体文体。

## 最后冷读

暂时忘掉所有规则，只回答下面几句。

哪里让我相信作者确实知道这件事。

哪里让我愿意继续读。

哪一段像人在处理一个问题，哪一段像模型在完成写作任务。

哪句话说得比材料大。

文章在哪一句已经结束。
